
# Demo / Interview Checklist

1. Open dashboard and show API health.
2. Select each of the four document types.
3. Upload a native PDF.
4. Upload a scanned/image-based document.
5. Show the validation and page-limit controls.
6. Open a stored result from the dashboard.
7. Explain evidence/page numbers.
8. Explain one PASS and one FAIL/NOT_APPLICABLE financial check.
9. Open `/docs` and demonstrate the REST contract.
10. Explain SQLite persistence and how you would migrate to PostgreSQL.
11. Explain the optional Gemini extraction path and deterministic fallback.
12. Explain security: env secrets, file validation, controlled errors and logging.
